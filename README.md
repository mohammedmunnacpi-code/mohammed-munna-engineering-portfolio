# Mohammed Munna — Engineering Portfolio

A responsive personal portfolio website built with semantic HTML, CSS, and vanilla JavaScript.

## Files

- `index.html` — page structure, profile content, and SEO/social metadata
- `style.css` — responsive layout, visual design, and animations
- `script.js` — language toggle, mobile navigation, scroll reveals, and local photo preview
- `sitemap.xml` — sitemap for search engines
- `robots.txt` — crawler guidance
- `assets/Mohammed-Munna-CV.pdf` — add your own resume PDF here

## Run locally

Open `index.html` in a browser. Google Fonts load online; the website has no JavaScript dependencies.

## Personalize before sharing

Replace `your-email@example.com`, `YOUR-LINKEDIN-USERNAME`, and `YOUR-GITHUB-USERNAME` in `index.html`. Add your own CV at `assets/Mohammed-Munna-CV.pdf`. Update the Open Graph image if you add a profile photo file.

The photo picker previews an image locally in the browser; it does not upload or save it to the website. Project cards are labeled as ideas, not completed projects. Add only verified project, certification, and achievement information.

## GitHub Pages

1. Open repository **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch `main` and folder `/ (root)`, then save.
4. The site should be available at `https://mohammedmunnacpi-code.github.io/mohammed-munna-engineering-portfolio/` after GitHub Pages finishes deploying.
